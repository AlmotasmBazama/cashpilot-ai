## انحدارات أُغلقت أثناء التنفيذ

1. overflow بمقدار 4px في بطاقة الحساب على الجهاز: رُبط ارتفاع البطاقة بمقياس النص واختُبر عند 150%.
2. قص وصف شاشة الإيصال: صار `CPAppBar` يسمح بسطرين بارتفاع مناسب.
3. زر إلغاء تجهيز الإيصال خرج جزئيًا من viewport الاختبار: أصبح الاختبار يمرر حتى يكون هدف اللمس كاملًا قبل النقر.
4. قص تسمية Transactions: استُخدم تخطيط نص متكيف واختبار دلالي عند 320px.
5. قص الإحصاء الثالث في Accounts: استُبدل الشريط الأفقي بثلاث بطاقات متساوية.

## سلامة الوظائف

- لم تتغير قواعد Finance Engine أو قواعد الأرصدة.
- لم يتغير Groq أو Cloud Run أو App Check أو receipt routing.
- لم يُفعّل تنفيذ مالي تلقائي.
- بقيت المعاينة والتأكيد الصريح، ومنع التكرار، وسياسات owner scope كما هي ومغطاة بالمجموعة الكاملة.
