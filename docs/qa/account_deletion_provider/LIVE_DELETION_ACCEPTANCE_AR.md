# القبول الحي لمزوّد حذف الحساب

التاريخ: 2026-08-21  
الجهاز: Pixel 6 AVD على `emulator-5554`، Android 17 / API 37  
الخدمة: `cashpilot-account-deletion-staging-00003-q4b`  
النتيجة: **PASS**.

## الضوابط

- استُخدمت أربعة حسابات اصطناعية جديدة: A وB للتحكم، C للحذف المتقطع، وD للحذف النظيف.
- لم تحفظ أية credentials أو UID أو tokens أو owner scopes في الأدلة.
- لم يُنفذ `pm clear` ولم تُمسح بيانات التطبيق.
- لم تُحذف App Check debug registration الحالية.
- زُرعت بيانات Cloud مع مجموعة متداخلة غير معروفة، وبيانات Drift وإيصال وملف وإعدادات ضمن نطاق الهدف.

## الحسابان المحجوران المذكوران في خط الأساس

عند بدء هذا التشغيل كانت الفرضية قد أصبحت قديمة: البحث Admin الدقيق للنمط
الاصطناعي أعاد صفراً، والتطبيق كان signed out ولا يعرض continuation. لم يُحذف
أي حساب يدوياً ولم يُضعف الحجر. سجلات المراجعة السابقة للخدمة المستقلة أظهرت
وصول عمليات محمية إلى مراحل الإكمال. نتيجة التنظيف هي **PASS / ALREADY CLEAN**:
صفر حساب مطابق وصفر عملية محلية قابلة للاستئناف. لذلك استُخدمت C وD لإثبات
المسار الحي كاملاً بدلاً من ادعاء استئناف حسابين غير موجودين.

## D — الحذف النظيف

اكتمل التسلسل بلا انقطاع: إعادة المصادقة، الحجر، الحذف العودي والتحقق من
السحابة، تنظيف Drift والإيصالات وHive/AI/settings، ثم حذف Auth أخيراً. كانت
كل العدادات النهائية صفراً، ولم تعرض الواجهة نجاحاً قبل اكتمال Auth.

## عدم الإحياء والعزل

بعد استعادة الشبكة وتشغيل العمال، أُعيد فتح التطبيق وانتُظر 30 ثانية. بقيت
شجرتا C وD السحابيتان فارغتين، وبقيت العدادات المحلية والملفات صفراً، ولم تعد
البيانات. قبل تنظيف fixtures الاصطناعية أثبت hash canonical لحالة A وB أن
المستخدمين غير المستهدفين لم يتغيرا. بعد الإثبات حُذف A وB ضمن تنظيف الاختبار؛
لم يبق أي حساب اصطناعي أنشأه التشغيل.

ملف Hive append-only قد يحتفظ بثلاث مطابقات bytes تاريخية لنطاق محذوف، لكنها
ليست قيماً منطقية حية. فحص Hive على نسخة آمنة أثبت صفر user-data/settings entry
ومعلّمة terminal deletion tombstone واحدة مقصودة لكل هدف. المعلّمة ليست بيانات
مالية أو ذاكرة مستخدم؛ هي سياج دائم يمنع جلسة Auth قديمة من الإحياء، ولا يجوز
حذفها لإجبار عداد bytes الخام على الصفر.

## النتيجة الجامعة

`interrupted=true`, `clean=true`, `controlsPreservedBeforeCleanup=true`,
`noResurrection=true`, `complete=true`. خرج مشغّل القبول بالرمز 0.
