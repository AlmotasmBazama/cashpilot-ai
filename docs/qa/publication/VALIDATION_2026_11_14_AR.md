# مراجعة المصدر وتجهيزه للنشر — 14 نوفمبر 2026

هذه مراجعة للنسخة المصدرية الحالية، وليست شهادة جاهزية للنشر في المتاجر.
حُفظت تغييرات المساعد وتحليلات المصروفات الموجودة قبل المراجعة، وفُحصت مع بقية التطبيق.

## الإصلاحات

- رفض مبالغ العمليات المعلقة غير الموجبة والعملات المخالفة للحساب قبل أي حفظ؛ تبقى العمليات المعلقة بلا أثر على الرصيد.
- إعادة التحقق من الميزانية عند الإنشاء حتى عند تجاوز مصنع الكيان.
- تحديث نطاق تحليلات المصروفات عند تغير البيانات ومرور الوقت، وتصحيح حدود الأسبوع عبر التوقيت الصيفي وحدود الثانية في SQLite.
- رفض نتيجة قراءة التحليلات المتأخرة بعد إبطال جلسة المالك.
- اشتراط سجل التدقيق وسياسة التأكيد لتعديل/حذف/التراجع عن العمليات بواسطة المساعد، كما في الإنشاء.
- إلغاء قراءة استجابة المزود عند تجاوز الحدود أو فشل فك النص، والتقاط انقطاع العميل أثناء المصادقة.
- تحديث تبعيات الخدمتين، وترحيل عقد Zod مع الحفاظ على اختبارات المخططات، ومواءمة الحاويات وCI على Node 24.
- إضافة README عربي/إنجليزي، ودليل مساهمة وسياسة أمن وقوالب GitHub وفحوص آلية مثبتة الإصدارات.
