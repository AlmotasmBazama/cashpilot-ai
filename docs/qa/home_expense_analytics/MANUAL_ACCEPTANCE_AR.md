## قبول Web

نجح `flutter build web --no-pub`. عند التشغيل المحلي ظهرت شاشة الدخول، لكن تسجيل الضيف رُفض لأن طريقة الدخول غير مفعلة/محجوبة في Firebase، وسجل App Check استجابة 403. لم تُغيّر إعدادات المشروع أو App Check. لذلك حالة لوحة Home على Web هي **محجوبة بيئيًا** وليست ناجحة يدويًا. التكوين الواسع مغطى باختبار widget بعرض 900px ولقطة tablet من Flutter Android renderer.
