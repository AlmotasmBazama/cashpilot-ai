# دليل التنظيف المنزوع الحساسية

تمت إزالة ما أنشأته المهمة محلياً فقط:

- نسخ APK المسحوبة والمعاد توقيعها وملف التوقيع الجانبي.
- صور الشاشة وملفات UI XML الخاصة بهذا التشغيل.
- نسخ Flutter runtime وAndroid SDK وGradle home وPub cache المؤقتة.
- أداة فحص route المؤقتة وملفاتها على الجهاز.
- إعادة `android/local.properties` و`.dart_tool/package_config.json` إلى مسارات SDK الأصلية.

لم تُحذف ملفات QA، ولم تُمسح بيانات التطبيق، ولم تُحذف App Check registration، ولم تُمس موارد Cloud Run أو بيانات تطوير موجودة.

لم يُحذف الحساب الاصطناعي المحجور ولا حساب التحكم من السحابة: مزود الحذف الموثوق غير متاح ولا توجد صلاحيات Admin في هذه البيئة. الحذف اليدوي أو مسح بيانات التطبيق كان سيخفي العطل ويكسر إثبات الاستئناف، لذلك بقيت هذه الموارد بند تنظيف P0 معلّقاً.
